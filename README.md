# File Archiving Automation Using Shell Scripting

## Project Overview
This project automates the process of identifying large files on a Linux system, compressing them using gzip, and moving the compressed files into an archive directory.

## Technologies Used
- Linux (Ubuntu)
- Bash Shell Scripting
- gzip
- find
- Git and GitHub

## Features
- Checks whether the base directory exists.
- Creates an archive directory if it does not exist.
- Finds files larger than 20 MB.
- Compresses files using gzip.
- Moves compressed files to the archive directory.
- Includes basic error handling.

## Project File
- `archive_project.sh` — Main shell script.

## How to Run
```bash
chmod +x archive_project.sh
./archive_project.sh
```

## Learning Outcomes
- Linux file management
- Bash scripting and loops
- Conditional statements
- File compression and archiving
- Basic error handling
